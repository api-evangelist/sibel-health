## What an integrator needs to know first

Sibel Health operates a real, live REST API, and it is not publicly documented.

- The API base is https://api.sibelhealth.com/jsn/alpha. This was read from the JavaScript bundle
  of Sibel's own datahub.sibelhealth.com web application, not guessed.
- The host is an AWS API Gateway deployment. Every anonymous request returns HTTP 403 with either
  {"message":"Forbidden"} or {"message":"Missing Authentication Token"}.
- The gateway advertises Authorization and X-Api-Key as accepted credential headers, and
  DELETE, GET, HEAD, OPTIONS, PATCH, POST and PUT as accepted methods.
- There is no developer portal, no API reference, no OpenAPI or Swagger description, no GraphQL
  endpoint, no AsyncAPI or webhook catalog, no MCP server, no A2A agent card, no /.well-known/
  document of any kind, and no public SDK package on any registry.
- developer.sibelhealth.com holds a valid TLS certificate but does not answer HTTP.
- Access is arranged commercially: https://sibelhealth.com/request-demo/

## Interoperability

The strongest integration signal Sibel publishes is at the device layer, not the cloud layer.

- ANNE One is certified to the IEEE 11073 Service-Oriented Device Connectivity (SDC) family of
  standards, announced 2026-06-10 alongside EU MDR Class IIb CE Mark certification. Sibel states the
  platform "is designed to communicate natively with other SDC-compatible devices and hospital IT
  systems, without proprietary gateways or vendor lock-in."
- No FHIR, US Core, SMART-on-FHIR, HL7 v2 or DICOM surface is published or referenced.
- A Sibel software development kit exists — two August 2024 FDA clearances specifically enabled
  ANNE Chest and ANNE Limb to work with third-party applications built against it — but the SDK is
  released to strategic partners and is not distributed through any public registry.

## Regulatory status

Five FDA 510(k) clearances, confirmed against the FDA's own openFDA device database:

- K223711 — ANNE One — cleared 2023-08-10
- K240305 — ANNE Limb — cleared 2024-05-28
- K240251 — ANNE Chest — cleared 2024-06-03
- K242842 — ANNE View, Central Hub — cleared 2025-01-08
- K253021 — ANNE Maternal — cleared 2026-02-26

Plus EU MDR (2017/745) Class IIb CE Mark for ANNE One, 2026-06-10. Sibel states on its own product
page that "ANNE Care is HIPAA and GDPR compliant." No SOC 2, ISO 27001 or trust center is published.
